# Online Learning Behaviour Analysis Dashboard

## Overview

This project analyzes student learning behavior to understand engagement, course completion, learning patterns, 
and academic performance across different learning environments. The dashboard provides interactive insights into student activity,
performance metrics, and learning trends.

## Objective

To analyze student engagement and learning behavior by identifying patterns in course completion, learning hours, quiz attempts, 
assignments, and performance across multiple dimensions.

## Tools Used

* Microsoft Power BI
* DAX
* Data Cleaning
* Data Transformation
* Data Visualization

## Dataset Information

* Total Students: 1,000+
* Multiple Countries
* Various Fields of Study
* Different Devices and Learning Modes

## Project Workflow

* Data cleaning and preprocessing
* Data transformation and validation
* KPI creation and DAX calculations
* Data modeling
* Visualization design
* Dashboard development

## Key Features

* KPI cards for student count, course completion, learning hours, and quiz attempts
* Country-wise student performance analysis
* Device usage analysis
* Education-level segmentation
* Learning mode comparison
* Interactive filters and slicers
* Dynamic visualizations and trend analysis

## Key Insights

* Identified countries with higher course completion rates
* Analyzed device preferences among students
* Compared learning performance across education levels
* Evaluated engagement patterns across different learning modes
* Identified fields of study with higher assignment submissions

## Dashboard Highlights

* Student engagement tracking
* Performance monitoring
* Comparative analysis
* Interactive reporting
* Real-time filtering
